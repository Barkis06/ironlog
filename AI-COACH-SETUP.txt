IronLog v2.3 - In-App AI Coach Setup

A) Create an OpenAI API key at https://platform.openai.com/api-keys. ChatGPT Plus billing does not include API usage.
B) Netlify: Open your existing serene-taffy-82953f project > Project configuration > Environment variables. Add:
   OPENAI_API_KEY = your OpenAI Platform API key (secret, ONLY in Netlify).
   IRONLOG_COACH_ACCESS_CODE = a unique private code with 16 or more characters, preferably 24+ random characters.
   Optional IRONLOG_AI_MODEL = gpt-5.4-mini (the default).
   If scopes are available, ensure these variables are available to Functions.
C) Trigger a fresh Netlify deploy after adding the environment variables.
D) In your installed IronLog app, open AI Coach, type only the IRONLOG_COACH_ACCESS_CODE you created, tap Save code, and ask a question.

SECURITY:
Never put the OpenAI API key into GitHub, your website, your phone's chat access-code field, or any ChatGPT conversation. Your private code is checked server-side; it is stored on your phone. A basic per-instance throttle reduces repetitive calls but is NOT a guaranteed spending cap. Set API budget alerts / usage limits and choose a long unique code.
The coach's local conversation messages (not workout logs) are sent over HTTPS to Netlify's function then to OpenAI. Workout data remains under localStorage key ironlog_strength_v1, unchanged. No account sync.
